# Enhanced Task Management Application

## Overview
The Enhanced Task Management Application is designed to help users efficiently manage their tasks, set priorities, and track progress. This application serves as a robust tool for both personal and professional task management.

## Features
- **Task Creation**: Easily create and customize tasks with titles, descriptions, and due dates.
- **Priority Levels**: Assign priority levels (High, Medium, Low) to categorize tasks based on urgency.
- **Due Dates and Reminders**: Set due dates and receive reminders to ensure tasks are completed on time.
- **Task Tracking**: Monitor the progress of tasks and mark them as complete when finished.
- **User Authentication**: Secure user authentication to maintain privacy and data integrity.

## Usage Instructions
1. **Installation**: Clone the repository:
   ```bash
   git clone https://github.com/Mashielkhan/Task-Management.git
   cd Task-Management
   ```
2. **Dependencies**: Install the necessary dependencies:
   ```bash
   npm install
   ```
3. **Starting the Application**:
   ```bash
   npm start
   ```
   Access the application in your browser at `http://localhost:3000`.

## Keyboard Shortcuts
- `Ctrl + N`: Create a new task.
- `Ctrl + D`: Delete the selected task.
- `Ctrl + R`: Mark task as complete.

## Browser Compatibility
This application has been tested and works seamlessly on:
- Google Chrome
- Mozilla Firefox
- Microsoft Edge
- Safari
